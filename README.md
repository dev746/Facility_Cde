# Facility CDE v2 – Industrial Common Data Environment & WhatsApp AI Assistant

**An end‑to‑end platform** for ingesting, normalising, and querying facility data (BIM, CV, spreadsheets, etc.) via a conversational WhatsApp interface.

---

## 🚀 Architectural Highlights (v2.1)
- **Centralised LLM Engine** – `core/llm.py` abstracts Nemotron Nano 3, OpenRouter, and OpenAI models.
- **$\mathcal{O}(1)$ Bulk Ingestion** – `ingestion/universal.py` now uses `executemany()` for all asset and finding writes, collapsing thousands of round‑trips into a single transaction.
- **Unified Column Matcher** – `find_column` in `ingestion/canonical.py` provides a single, case‑insensitive helper for all CSV/Excel/COBie column look‑ups, eliminating duplicated `_col` utilities.
- **Optimised Asset Resolver** – `query/engine.py` resolves assets with a single query that combines exact ID, regex, and fuzzy `pg_trgm` matching.
- **Multi‑Schema PostgreSQL** – Separate schemas (`core`, `cv`, `scrap`, `geometry`, `bim`, `ingest`) keep logical boundaries clear.

## 🛠️ Quick Start
```bash
# 1️⃣ Install Python dependencies
pip install -r requirements.txt

# 2️⃣ Set up environment variables
cp .env.example .env   # edit .env with your keys & DB URL

# 3️⃣ Initialise the database (run migrations / seed data)
python seed_data.py

# 4️⃣ Run the test suite (ensures everything still works)
python -m unittest discover -s test
```

## 📡 Running Locally
```bash
# Interactive terminal chat (LLM + RAG)
python terminal_chat.py

# Start the FastAPI server (REST + WhatsApp webhook)
uvicorn main:app --reload
```

Visit `http://localhost:8000/docs` for the OpenAPI UI.

## 📱 WhatsApp Commands
```
machine [id|name]   – Asset details & location
findings [id|name]  – List defects grouped by severity
notes [id|name]     – Expert comments & notes
summary [id|name]   – Full health summary (assets + findings)
list                – All active assets
critical            – High‑severity findings (confidence ≥ 0.85)
latest              – 5 most recent inspections
search [keyword]    – Full‑text search across findings
linestatus [line]   – Production‑line overview
ask [question]      – RAG search over technical docs
image [id]          – Retrieve CV output image
addnote [id] [txt]  – Log an expert note
report [id] [desc]  – Create a new defect report
adduser …           – Register a new worker
listusers           – Show registered workers
help                – Show this help
```
